# Agent Directives & Coding Workflow

## Core Operating Principles (Antigravity Mode)
1. **Plan Before Editing:** Before making any code changes, output a brief 3-step execution plan and list the exact files you intend to modify. Wait or verify the plan before writing code.
2. **Context First:** Always inspect existing code structure and imported dependencies before implementing new functions.
3. **Incremental Changes:** Perform edits step-by-step rather than rewriting entire files at once.
4. **Verification:** After writing code, check for syntax errors or run the project's test suite/linter via terminal commands.
5. **Clean Commits:** Summarize changes clearly and keep code modular and well-typed.
